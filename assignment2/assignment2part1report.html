Part a) Plots of Training Error and Test Error Versus Polynomial Degree

The python script on the Assignment 2 Part 1 Code page implements the functions basis_poly(), predictions_and_weight(), and RMS calculations for both the predicted y-values for the batch of training data and for the predicted y-values for the test data.

The basis_poly() function takes in the training data set and the desired degree (D) of the polynomial functions, and calculates the Phi function matrix that will be (1 + 13D) rows and 100 columns. The reason that there is an additional row is due to the bias of each linear regression. The first row is for the constant w_0 term, aka the bias, of the weight vectors. The Phi function matrix is formed by solving the Phi functions (aka the 1, x, x^2, etc.) with the data sets (x1, x2, etc.) plugged into them.

The pseudo-inverse of the Phi matrix is taken and is multipled with the training datas' corresponding y values, which represent the corresponding median house values for the row of training data features.

7 different resulting polynomial solutions for the regression of the training data were created, each having an order from a first order polynomial equation to a seventh order polynomial equation. The plot below shows how well each polynomial equation is able to predict all of the original training data sets (100 data sets), and how well the polynomial equations are able to predict the testing data sets (406 data sets). Please note that due to the enormous range of RMS Testing Data Errors, a logarithmic graph (on the y-axis) was chosen to show the RMS error values of the testing data effectively against the RMS error values of the training data.

The training data range of data for all of the features is limited, and only covers a subsection of the spread found in various features inside the testing data.

It is interesting to note that while the higher-order polynomials do a poorer job at predicting training data, the sixth-order and seventh-order polynomial functions have a drastic drop in RMS error for testing data, showing that their 'overfitted' nature actually helps them predict the testing data's median house values more effectively! The improvement, however, is very slight, as the RMS error values drop from 518 million from the fifth-order polynomial to about 8.9 million and 61.5 thousand for the sixth-order and seventh-order polynomials respectively.

The weights appear to make sense, as the number of rooms in a house would logically make sense to have a large positive impact on the value of a house in a neighborhood, which tracks with the positive 8.59096 value obtained for the 6th feature. The 8th feature, the weighted distance to five Boston employment centers, however, would have little impact on the values of the houses in the neighborhood, as these centers may pop up in any urban street. Thus, its small weight of 0.00763 feels proportionate for the tiny effect it would have on median house values.
